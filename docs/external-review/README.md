# External Source Review Briefs

**Purpose:** Ask each source to correct how this repository represents their own work **without asking them to endorse the larger synthesis**.

The goal is adversarial accuracy: if a source thinks we have misunderstood, overstated, or omitted a key part of their work, we want that correction preserved before using their work to generate tests.

---

# General message to all reviewers

This repository is not asking you to endorse a unified theory. Your work is being treated as one independent input to a falsifiable research program.

Please focus on:

1. factual accuracy in how your work is summarized;
2. distinctions between what you directly observed, inferred, and speculated;
3. the strongest evidence against your preferred interpretation;
4. any dataset/source we should treat as canonical;
5. one or more observations that would seriously weaken or falsify the specific claim attributed to your work.

Corrections are more valuable than endorsements.

---

# Chris Lehto / Cosmic Octaves

## What the repo currently takes from the work

The Scale (S) branch asks whether the proposed approximately `10^24 m` recurrence survives corrected quantitative analysis and explicit null/selection models.

The repo does **not** infer regulation, UAP, or consciousness from the scale pattern alone.

## Review questions

1. Have we accurately stated the quantitative Cosmic Octaves claim?
2. Which scale table/dataset/selection rule should be treated as the canonical version?
3. Are any structures/scales in our current reconstruction included or excluded incorrectly?
4. What is the intended uncertainty on each scale measurement?
5. Which part of the hypothesis is the strongest scientific claim: approximate spacing, phase recurrence, organizational similarity, dynamics, or something else?
6. What observation or analysis result would convince you that the apparent recurrence is primarily selection/statistical artifact?
7. If the scale recurrence survives, what **new prediction** should it make beyond fitting the scales already used to identify it?

## Requested deliverable

A short correction note or annotated issue identifying factual errors and the canonical input data/definitions.

# Jacques Vallée / control-system hypothesis

## What the repo currently takes from the work

Vallée's writings provide theoretical/historical provenance for questions involving control systems, adaptive manifestations, witness/perceptual effects, deception/ambiguity, belief/cultural effects, and possible societal influence.

The repo does **not** treat these interpretations as empirical proof of a control system.

## Review questions

1. Have we accurately represented the control-system hypothesis?
2. Is it accurate to treat witness/perceptual effects, deception/ambiguity, and belief/cultural effects as central rather than incidental aspects of the model?
3. Are we overextending the model by formalizing a possible observer/societal feedback channel?
4. Which primary works/passages best state the control-system idea in its most mature form?
5. In your view, what would distinguish a genuine control process from recurrent anomalous events that merely correlate with social conditions?
6. What empirical observation would seriously weaken the control-system interpretation?
7. Is there a protected state, direction, or system-level quantity you intended the control system to regulate, or was the concept deliberately more open-ended?

## Requested deliverable

Corrections to our interpretation and pointers to the most definitive primary passages. Endorsement of the project is neither requested nor assumed.

# Patrick Jackson / proposed sphere network

## What the repo currently takes from the work

Jackson's model is treated as a **source of quantitative network hypotheses**, not evidence that a sphere network exists.

The project intends to test topology/coordination before making claims about literal object shape or identity.

## Review questions

1. Which parts of the network model are direct observations, which are inferences, and which are speculation?
2. Is there a canonical event/case catalog underlying the model?
3. Which cases have the strongest provenance and independent sensor evidence?
4. What specific roles/node classes do you propose, and what observable signatures distinguish them?
5. What temporal ordering, relay behavior, geometry, persistence, or response timing should a real network produce?
6. Which predictions can be frozen **before** an independent dataset is inspected?
7. What dataset/result would seriously weaken or falsify the network model?
8. Are there common descriptions of your work that you believe are inaccurate and should be explicitly avoided?

## Requested deliverable

An observation/inference/speculation correction table plus the smallest set of testable predictions you consider faithful to your model.

# Beatriz Villarroel / VASCO and POSS-I

## What the repo currently takes from the work

VASCO/POSS-I is treated as the strongest near-term empirical target because it offers published statistical claims, an active peer-reviewed methodological dispute, and candidate data for independent replication.

The repo does **not** assume the transient candidates are UAP, artificial objects, or Jackson spheres.

## Review questions

1. Which dataset/version should be treated as canonical for each published claim?
2. Can exact dataset checksums/version identifiers and data dictionaries be provided?
3. What are the precise inclusion/exclusion rules for the nuclear-window, Earth-shadow, and multi-transient analyses?
4. Which plate metadata, feature-validation fields, ML probabilities, or quality indicators are available to an independent replicator?
5. Which analysis code is canonical for the published effects?
6. Which parts of the data have already been used to choose hypotheses, windows, thresholds, or model specifications?
7. Is there a genuinely untouched dataset/epoch/instrument suitable for confirmation?
8. What do you regard as the strongest point in Watters et al. (2026), even if you disagree with their conclusion?
9. What analysis/result would convince you that the nuclear-window or Earth-shadow findings are primarily driven by observational/systematic effects?
10. Would you be willing to review a Stage-1 adversarial replication protocol **before** confirmatory analysis, focused on accurately representing both your model and the critical alternative?

## Requested deliverable

Canonical data/code pointers, corrections to our representation, and explicit falsification criteria.

# How to record responses

Do not silently rewrite history after receiving source feedback.

For each response:

1. save the date and source;
2. record the original project statement;
3. record the correction/objection;
4. update the relevant file with a note describing the change;
5. preserve any material disagreement in `ADVERSARIAL_EVIDENCE.md`;
6. update `CLAIM_LEDGER.md` if evidentiary status changes;
7. do not upgrade status because a source personally agrees with the larger synthesis.

Source review improves **representation accuracy**, not evidentiary rank.
