## PREREGISTRATION CONTRACT (Frozen — do NOT modify after data analysis begins)

### 1. System Boundary (Q10 Criterion 1)
- **Inside:** Soil / substrate / metallic residue sample collected at site of documented UAP observation (Socorro 1964, Valensole 1965, Ubatuba 1957, or equivalent V0 case from primary-source-register.md C-026/C-030/C-031/C-033)
- **Outside:** Native soil at same geographic coordinates but >50m from observation point; laboratory control sample (terrestrial aluminum alloy of known composition); blank sample (no substrate)
- **Boundary definition:** Sample collected within documented landing/impact zone (≤10m from center of observation point), compared to paired control ≥50m away, and to independent lab blank
- **Freeze:** Boundary defined now; any deviation from these parameters during analysis must be reported as protocol deviation, not adjusted

### 2. Protected Variable / Viability Region (Q10 Criterion 2)
- **Primary variable:** Residue composition by weight % of Al, Mg, Sn, Zn, Bi (matching measured elements across sources), measured via XRF / ICP-MS
- **Specific values being tested (from verified sources — do NOT change):**
  - Confrontations: 93.7% Al / 4.8% P / 0.9% Fe (with Mg, Sn present) — observed
  - AARO/ORNL: Mg-Zn-Bi (no Al % specified) — observed on different specimen
  - Ubatuba (Alt Propulsion): "almost pure magnesium" — observed
  - **Protected region:** Alloy composition within ±5% of source measurement (e.g., Al 88-98% for Confrontations-type; Mg dominant for Ubatuba-type)
- **Secondary variable:** Presence/absence of exotic elements (elements not in terrestrial metallurgical range — defined as elements with atomic number >92 or isotopic ratios outside terrestrial range per AARO isotopic analysis)
- **Freeze:** Primary and secondary variables defined; measurement instruments specified; calibration protocol defined

### 3. Identifiable Disturbances (Q10 Criterion 3)
- **Disturbance 1 — Sampling contamination:** Soil mixing, collection method, storage container, transport contamination
  - Mitigation: Sterile collection; glass (not plastic) containers; chain-of-custody documentation; photos at collection
- **Disturbance 2 — Native soil variation:** Soil chemistry varies with depth, season, weather, land use
  - Mitigation: Paired control sample at same site >50m away; multiple depths; seasonal replication if possible
- **Disturbance 3 — Laboratory method variation:** Different instruments (XRF vs ICP-MS) produce different absolute values
  - Mitigation: Both instruments used on same sample; cross-calibration with certified reference material (NIST SRM 500 or equivalent)
- **Disturbance 4 — Source ambiguity:** Different sources (Confrontations vs AARO vs Ubatuba) report different compositions (Al-Mg-Sn vs Mg-Zn-Bi vs pure Mg)
  - Mitigation: Treat as separate replication groups; do NOT combine measurements from different sources into single analysis; report per-source
- **Freeze:** All 4 disturbances identified; mitigation methods documented; deviation from mitigation must be reported

### 4. Candidate Feedback Pathway (Q10 Criterion 4)
- **Hypothesis:** Residue chemistry influences the system dynamics that produced the observation (i.e., the physical trace is part of the mechanism, not a byproduct)
- **Specific feedback:** Alloy composition (Mg/Al/Zn/Bi ratios) → thermal/electrical properties → interaction with soil/vegetation/atmosphere → observed physical effects (flattened vegetation, accelerated growth, physical impact)
- **Freeze:** Feedback pathway defined; must be tested by intervention (step 5)

### 5. Intervention Design (Q10 Criterion 5 — Causal Evidence)
- **Intervention 1:** Independent laboratory analyzes the same sample with a DIFFERENT method (e.g., if first is XRF, second is ICP-MS; if first is one lab, second is another lab)
  - Prediction: Composition should reproduce within ±5% (if true measurement) or diverge systematically (if method artifact)
- **Intervention 2:** Synthetic reproduction of observed alloy (e.g., aluminum-magnesium-tin at 93.7/close-to-Mg/Sn ratios) placed in control soil; observe vegetation/soil effects over 6-12 months
  - Prediction: If alloy IS part of mechanism, synthetic alloy should produce similar botanical effects (growth acceleration, calcium accumulation); if NOT part of mechanism, synthetic should show only terrestrial aluminum-alloy effects
- **Intervention 3:** Analysis of control site (>50m away, same geographic region) for comparison
  - Prediction: Control site should show NO Al-Mg-Sn alloy at observed percentages; should show native soil chemistry only
- **Freeze:** All 3 interventions defined before any analysis; any unplanned intervention must be reported; primary analysis must use pre-specified intervention (Intervention 1: independent lab replication)

### 6. Out-of-Sample Prediction (Q10 Criterion 6)
- **Prediction 1 (within-source):** If a second case from the same source family (e.g., second Confrontations case with residue analysis, or second Ubatuba-type case) is measured with same protocol, composition should fall within ±5% of first measurement (if mechanism is consistent) OR diverge (if case-specific)
- **Prediction 2 (cross-source):** If AARO-specimen (Mg-Zn-Bi) and Ubatuba (pure Mg) measurements are both real, they should have DIFFERENT isotopic signatures (different manufacturing sources) — this predicts non-identical origin, NOT a single source
- **Prediction 3 (conventional elimination):** If soil analysis shows NO foreign material (Project Blue Book result), the prediction is that conventional explanation is sufficient; if soil analysis shows foreign material, conventional explanation is insufficient
- **Freeze:** All 3 predictions written; analysis requires testing all 3; any untested prediction must be flagged

## ANALYSIS PLAN (Frozen — must follow this order)

**Step 1 — Independent replication (Intervention 1):**
Apply both instruments (XRF + ICP-MS) to same sample; compare results; if divergence >±5%, investigate method artifact before interpreting composition

**Step 2 — Control comparison (Intervention 3):**
Analyze paired control site; if control shows same alloy at same %, measurement is artifact of native soil; if control shows different chemistry, measurement reflects site-specific anomaly

**Step 3 — Cross-source comparison:**
Compare measurement to all verified sources (Confrontations 93.7% Al; AARO Mg-Zn-Bi; Ubatuba pure Mg; Revelations Ubatuba McDonnell). Do NOT assume identity — report per-source patterns.

**Step 4 — Conventional elimination (Q10 + C-011/C-030 protocol):**
Compare to industrial aluminum alloys (terrestrial); compare to atmospheric/soil contamination patterns; document why native explanation is insufficient if it is

**Step 5 — Out-of-sample (Prediction 1 + 2):**
If measurement reproduces within ±5% of source, test second case; if diverges, document divergence; do NOT adjust boundary or variable to force match
