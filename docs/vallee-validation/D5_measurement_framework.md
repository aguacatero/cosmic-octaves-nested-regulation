## PER-ANCHOR EXECUTION NOTES (what to do in new session)

**For each anchor, the user executes these steps (independently — no evidence inheritance):**

### Step 1 — Source the passage
- Open `~/Downloads/JacquesValleePassporttoMagonia.pdf` (verified 16MB, Aug 28 2023)
- Locate passage per claim-ID table above (pages 148-178 for Key Insights; Dense Summary pages as noted)
- Extract neutral paraphrase (NOT interpretation; NOT Vallée's conclusions)
- Record: source_id, page, chapter, exact bounded quote → commit to `docs/vallee-validation/D5_measurements.md`

### Step 2 — Define measurement method
- Per Q10 criteria for that anchor (see Q10 Criteria Map column above)
- Define: system boundary, protected variable, disturbances, feedback pathway, intervention test, out-of-sample metric
- Write method in own words — NO Vallée interpretation, just measurement protocol
- Commit to `D5_measurements.md` under that anchor's subsection

### Step 3 — Apply Q10 checklist
- For each of 6 criteria: YES / NO / PARTIAL + notes
- ALL 6 must be YES (or PARTIAL with replication plan) for V1-eligible tag
- If any NO: document why, document what would make it YES, tag still-SPECULATIVE

### Step 4 — Record measurement result
- Actual measured value (with units) OR "not measured yet" with reason
- Replication count (how many independent samples/cases)
- Control site / baseline if applicable
- Commit to `D5_measurements.md`

### Step 5 — Tag V1 status
- V1-ELIGIBLE: all 6 Q10 YES + replication ≥1 + preregistered before analysis
- STILL-SPECULATIVE: any Q10 NO, or replication = 0, or no preregistration
- Commit tag to `D5_measurements.md`

### Step 6 — Bridge implication
- If V1-ELIGIBLE for anchor: note that this anchor contributes to B-IV consideration (but still needs ALL 7 anchors + novel joint prediction per v2 §56-63)
- If STILL-SPECULATIVE: note bridge remains SPECULATIVE per current architecture
