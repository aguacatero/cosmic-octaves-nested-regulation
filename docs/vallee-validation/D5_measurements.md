## Q10 Criteria Reminder (per docs/hypothesis-families/regulation.md)

1. **Independently defined system boundary** — what is inside vs outside
2. **Measurable protected variable or viability region** — what stays within bounds
3. **Identifiable internal/external disturbances** — what pushes variable away
4. **Identifiable candidate feedback pathway** — how state influences subsequent action
5. **Causal evidence** — disrupting/conditioning pathway changes disturbance rejection (intervention test)
6. **Closed-loop model outperforms open-loop** in out-of-sample prediction
