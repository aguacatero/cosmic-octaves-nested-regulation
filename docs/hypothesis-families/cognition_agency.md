# Cognition / Agency / Consciousness (C)

**Status**: PARKED (framework only).  
**Activation requires**: Specified candidate regulated/information-processing system with defined boundaries and Q10 criteria met.

## Sub-branches
- C0 — Complex dynamics (no claim of cognition; theory-neutral measurement)
- C1 — Learning / information processing (requires information integration evidence)
- C2 — Agency (requires Q12 criteria)
- C3 — Consciousness — operationally unresolved (see §5.8 constitutional rule)

## Agency Criteria (Q12 — Minimum Evidence for Agency)
All must be demonstrated:
1. Persistent outcome preference across contexts
2. Multiple possible actions with different consequences
3. Action selection changes appropriately with environmental change
4. Flexible response to novel perturbation (not merely fixed feedback)
5. Possible sacrifice of short-term stability for longer-term outcomes
6. Explicit non-agent model predicts worse than an agent/policy model
7. Intervention on information available to the system predictably changes behavior

## Consciousness (C3) — Operationally Unresolved
**Working rule**: No currently accepted theory-neutral test establishes consciousness in arbitrary non-neural systems. A consciousness hypothesis may only be activated for a candidate architecture to which a consciousness theory makes an explicit, preregisterable prediction.

**Do not use**: Generic IIT/GWT-derived metrics as a universal consciousness meter.  
**Do not claim**: Regulation → consciousness; cognition → consciousness; agency → consciousness.

## Activation Path
1. C0 → C1 → C2 → C3 (each gate is independently met)
2. Each sub-branch needs frozen, theory-neutral operational criteria
3. No consciousness claims without a specific candidate architecture and a specific theory with a specific preregisterable prediction

## Connection to Other Branches
Do NOT infer consciousness from anomalous events. Do NOT infer agency from adaptation without Q12-style tests. Do NOT infer regulation from temporal correlation alone.
