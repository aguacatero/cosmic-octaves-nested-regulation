# Cognition / Agency / System Consciousness (C)

**Status**: PARKED (framework only).  
**Activation requires**: Specified candidate regulated/information-processing system with defined boundaries and operational criteria met.

## Scope

This branch asks whether the **putative higher-level system itself** demonstrates cognition, agency, or consciousness.

It does **not** ask whether human perception/consciousness is being modified as part of an anomalous information channel. That separate question belongs to `observer_channel_modulation.md` (O).

```text
C = what is the putative system capable of?
O = is the human observer channel being modified?
```

Evidence for O does not establish C, and evidence for C does not establish O.

## Sub-branches
- C0 — Complex dynamics (no claim of cognition; theory-neutral measurement)
- C1 — Learning / information processing (requires information-integration / learning evidence)
- C2 — Agency (requires explicit agency criteria)
- C3 — System consciousness — operationally unresolved

## Agency Criteria (Q12 — Minimum Evidence for Agency)
All must be demonstrated:
1. Persistent outcome preference across contexts
2. Multiple possible actions with different consequences
3. Action selection changes appropriately with environmental change
4. Flexible response to novel perturbation (not merely fixed feedback)
5. Possible sacrifice of short-term stability for longer-term outcomes
6. Explicit non-agent model predicts worse than an agent/policy model
7. Intervention on information available to the system predictably changes behavior

## System Consciousness (C3) — Operationally Unresolved

**Working rule**: No currently accepted theory-neutral test establishes consciousness in arbitrary non-neural systems. A system-consciousness hypothesis may only be activated for a candidate architecture to which a specific consciousness theory makes an explicit, preregisterable prediction.

**Do not use**: Generic IIT/GWT-derived metrics as a universal consciousness meter.  
**Do not claim**: Regulation → consciousness; cognition → consciousness; agency → consciousness.

### Consciousness remains in scope

C3 is parked because its evidence requirements are unresolved, **not because consciousness is excluded from the project**.

The project may investigate consciousness in two distinct ways:

1. **O branch:** whether human consciousness/perception behaves as a modifiable observer/information channel;
2. **C branch:** whether the putative higher-level system itself meets a theory-specific consciousness criterion.

The first can potentially become empirically tractable without first solving the second.

## Activation Path
1. C0 → C1 → C2 → C3 (each gate independently met)
2. Each sub-branch needs frozen operational criteria
3. No system-consciousness claim without a specific candidate architecture and a specific theory with a specific preregisterable prediction

## Connection to Other Branches

- Do NOT infer system consciousness from anomalous events.
- Do NOT infer system consciousness from observer-channel modulation.
- Do NOT infer agency from adaptation without agency-specific tests.
- Do NOT infer regulation from temporal correlation alone.
- Observer-channel evidence may motivate later C hypotheses, but does not promote C automatically.
