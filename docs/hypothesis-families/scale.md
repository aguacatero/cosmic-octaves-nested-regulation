# Regulation (R)

**Status**: Active (calibration phase) — NOT connected to S during MVP.  
**Goal**: Test whether candidate control-dynamics can exhibit causal feedback regulation.

## Calibration
Benchmark detector against:
- **Positive controls**:
  - Thermostat / engineered feedback
  - Bacterial chemotaxis
  - Mammalian glucose regulation
  - Immune feedback
  - Established ecological feedback
- **Negative controls**:
  - Damped oscillator
  - Passive thermal equilibration
  - Diffusion
  - Gravitational relaxation
  - Autocorrelated stochastic processes

## Criteria (Q10)
1. System boundary
2. Protected variable / viability region
3. Identifiable disturbance
4. Candidate feedback pathway (state → action)
5. Causal evidence (disrupt → changes rejection)
6. Closed-loop model outperforms open-loop
