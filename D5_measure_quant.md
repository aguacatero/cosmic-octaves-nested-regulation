# D5 — Quantitative Measures (ELI5 / brief)
10 dynamics → measure at each scale (subatomic / bio / social / cosmic)
- 1 state: value at time t (e.g. size L)
- 2 deviation: |value - setpoint| (how off from ideal)
- 3 sensing: does system see its own state? (feedback exists?)
- 4 latency: time from deviation → response
- 5 strength: how big is the correction?
- 6 direction: is correction pushing back (negative feedback) or away (positive)?
- 7 termination: does control stop at a point (no runaway)?
- 8 adaptation: setpoint changes when environment changes (learning / memory)
- 9 memory: does previous deviation change future correction?
- 10 oscillation: does value swing (like heartbeat)?
Each needs ONE number per scale. Without number → gap (D7 A2-A7).
Cross-scale protocol: same 10 dynamics, different measurement method. No mixing of units. Report separately.
