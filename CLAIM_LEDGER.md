# Claim Ledger

**Date:** 2026-09-18  
**Purpose:** Prevent observations, source claims, interpretations, project hypotheses, and conclusions from collapsing into one another.

## Status vocabulary

- **OBSERVATION** — directly measured/reported datum or documented project event.
- **SOURCE CLAIM** — a claim made by an external source/author.
- **SOURCE INTERPRETATION** — a source's explanation of observations.
- **OUR HYPOTHESIS** — a project-generated claim proposed for testing.
- **OUR PREDICTION** — a preregistrable consequence of a hypothesis.
- **SUPPORTED** — survived the stated current test; scope limited to that test.
- **CONTESTED** — credible evidence/analysis points in materially different directions.
- **UNTESTED** — formulated but not yet subjected to an adequate confirmatory test.
- **INVALIDATED** — a specific analysis/result was shown defective; does not automatically falsify the parent hypothesis.
- **BLOCKED** — cannot currently be executed because required data/sample/access is unavailable.

## Rules for using this ledger

1. Never upgrade a source interpretation into an observation.
2. Never upgrade a peer-reviewed result into consensus merely because it passed peer review.
3. A contested claim stays contested until a predeclared adjudication or independent body of evidence resolves the material disagreement.
4. A bridge cannot borrow status from its parents.
5. A failed analysis is preserved with `INVALIDATED` status rather than deleted.
6. Any new high-level claim should be added here before it appears in the README as anything stronger than a question/hypothesis.
